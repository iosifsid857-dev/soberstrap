# SoberStrap

Менеджер модов в духе Bloxstrap для [Sober](https://sober.vinegarhq.org/) — Roblox на Linux. Внешний вид, фильтры
графики и настройки. Всё меняет только то, что видишь ты сам: никаких читов и изменений в игре.

## Что умеет

* **Фильтры** — 10 фильтров поверх готовой картинки: сочно, кино, мечта, мультик, комикс, пиксель-арт,
  ретро-телевизор, нуар, зима, Хэллоуин. У каждого есть ползунки. Плюс резкость AMD CAS. На Windows такие
  фильтры для Roblox (ReShade) блокирует античит, здесь они работают через vkBasalt.
* **Темы «Новый год» и «Хэллоуин»**, в том числе автоматически по дате:
  * курсор, солнце и луна;
  * значок загрузки, меню паузы, искры;
  * снег или угольки поверх игры.
* **Курсоры** — стрелка, точка, прицел или своя картинка.
* **Шрифт интерфейса** — любой шрифт с русскими буквами.
* **Графика** — режим качества Sober и разрешённые настройки Roblox.
* **Счётчик FPS** — MangoHud.
* **История игр** — во что и сколько играл, с кнопками «Играть снова» и «На тот же сервер».
* **Цвет эффектов** — цветные взрывы и силовое поле.
* **Свои моды** — папки со структурой `content/...` в `~/.local/share/soberstrap/mods/`.
* **Кнопка «Вернуть всё как было»**.

## Установка

```
git clone https://github.com/iosifsid857-dev/soberstrap && cd soberstrap
python3 soberstrap.py
```

Что нужно:
* Sober, запущенный хотя бы один раз;
* Python 3 с пакетами `PySide6`, `numpy` и `Pillow`.

Для счётчика FPS:

```
flatpak install flathub runtime/org.freedesktop.Platform.VulkanLayer.MangoHud/x86_64/26.08
```

Для фильтров: `scripts/build-vkbasalt-ext.sh`. Скрипт собирает vkBasalt и ставит его как расширение Flatpak.
